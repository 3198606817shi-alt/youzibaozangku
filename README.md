# 笔记视频提取器

这是一个仅在Mac本机运行的非官方个人工具。页面保持原版“小红书数据提取”布局，可粘贴单条笔记、达人主页或短链，按原有流程完成抓取、转写、写入飞书和上传封面。

## 下载与安装

1. 受邀用户登录GitHub后，在右侧`Releases`下载`笔记视频提取器-v1.0.0-mac.zip`。
2. 解压后双击`安装.command`。如果Mac提示无法验证开发者，请右键该文件，选择“打开”。
3. 按向导安装依赖、完成自己的飞书授权，并粘贴自己的飞书多维表格完整链接。
4. 转写密钥采用隐藏输入，只保存到当前Mac钥匙串。
5. 安装完成后双击桌面的“笔记视频提取器”。

本应用未使用苹果Developer ID签名和公证。首次打开桌面应用时，如果Mac拦截普通双击，请右键应用并选择“打开”；仍被拦截时，到“系统设置→隐私与安全性”中选择“仍要打开”。完成一次放行后可正常双击。

需要Python 3.10以上和Node.js。飞书授权使用官方[lark-cli](https://github.com/larksuite/cli)。

## 飞书表格要求

使用者必须准备自己的多维表格。目标数据表需要以下字段：

`笔记标题`、`笔记类型`、`达人昵称`、`发布时间`、`点赞数`、`收藏数`、`评论数`、`逐字稿`、`笔记链接`、`达人主页链接`、`来源类型`、`封面图`。

安装器只读取并检查字段，不会自动建表、改字段或写测试记录。

## 日常使用

1. 双击桌面应用，浏览器会打开`http://127.0.0.1:8766`。
2. 把小红书链接粘贴到输入框，一行一个。
3. 选择时间范围、是否转写、是否在转写后删除本地视频。
4. 点击“开始提取”，在运行日志中查看进度。
5. Cookie过期时点击右上角“更新Cookie”。Cookie只保存到Mac钥匙串。

重复双击不会启动第二个服务。退出时在Dock中右键应用图标并选择“退出”，或让应用获得焦点后按`Command+Q`。

## 本地数据

程序与非敏感配置位于：

```text
~/Library/Application Support/笔记视频提取器/
```

其中`settings.json`只保存飞书Base、数据表标识和转写接口设置；Cookie和转写密钥保存在Mac钥匙串。下载的视频、封面和元数据位于该目录下的`downloads/`。

## 更新与卸载

- 更新：下载新Release并重新运行`安装.command`。替换应用不会删除已有配置和数据。
- 卸载：先退出工具，再删除桌面应用和上述Application Support目录；如需彻底清理，另外在“钥匙串访问”中删除`com.youzi.note-video-extractor`相关项目。

删除Application Support目录会同时删除下载内容，操作前请确认是否需要备份。

## 常见问题

- 抓取失败：通常是Cookie过期、账号风控、笔记权限限制或平台接口变化。
- 转写失败：检查密钥余额、网络和音频质量；转写可能产生第三方费用。
- 飞书检查失败：确认当前飞书账号有权访问目标表格，字段名称完全一致。
- 端口被占用：退出占用8766端口的其他程序后再试，本工具不会主动结束其他程序。
